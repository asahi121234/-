# 投稿ルール（ライターと審査担当は必ず守る）

## 必須
1. **PR表記**：投稿の冒頭か、リンクの直前に `#PR` を入れる（ステマ規制・2023年10月施行）。
2. **アフィリエイトリンク**：楽天APIが返す `affiliateUrl` をそのまま使う。書き換え・短縮サービス経由は禁止。
3. **文字数**：500文字以内（Threadsの上限）。リンクも含めて数える。
4. **事実だけを書く**：価格・レビュー件数・レビュー平均は、APIで取得した値のみ使う。値には「投稿時点」と添える（価格は変わるため）。
5. **使っていないものを「使った」と書かない**：実体験のふりは禁止。「レビューで多かった声」「こんな人に向いていそう」など、根拠が分かる書き方にする。

## 禁止
- `rules/ng_words.txt` に載っている表現
- 効果・効能の断定（「〜が治る」「〜が消える」）
- 根拠のない最上級（「No.1」「最安値」）。楽天ランキングの順位を書くときは「楽天◯◯ジャンルのデイリーランキングで◯位（投稿時点）」のように出典と時点を書く
- 他社や他商品をおとしめる比較
- 医薬品・サプリ・ダイエット・成人向けなど、`config.json` の除外ジャンルの商品
- 同じ文面の使い回し（スパム判定の原因になる）

## 書き方のコツ（推奨）
- 1行目で「誰の、どんな悩み」かを示す
- 商品名は短くする（楽天の商品名は長いので、要点だけ）
- ハッシュタグは `#PR` を含めて2個まで
- 絵文字は控えめに（0〜2個）

# 普通の投稿（リンクなし）のルール

アフィリエイト投稿だけだと宣伝用アカウントに見えるので、**アフィリエイト1件につき普通の投稿を2件**（`config.json` の `normal_posts_per_affiliate`）混ぜる。

## ネタの種類（キャラクター「ついポチ予備軍」に合わせる）
| 型 | 例 |
|---|---|
| `ランキング観察` | 「最近ランキングに加湿器が増えてきた。もう冬支度の季節か」 |
| `あるある` | 「カートに入れたまま3日経つと、だいたい買わない説」 |
| `質問` | 「みんなポチる前にレビュー何件くらい読む？」 |
| `季節・イベント` | 「お買い物マラソン前って、カートの中身見直しがち」 |
| `迷い中の独り言` | 「ほしい物リストが増える一方で、減らない問題」 |
| `買い物の考え方` | 「レビュー★5だけじゃなく★3の声を読むと失敗しにくい気がする」 |

## 必須
- **リンクを入れない**（楽天のリンクも、ほかのURLも）
- **特定の商品名・ショップ名を出さない**。出すと宣伝になるので、その場合はアフィリエイト投稿として `#PR` を付ける
- 話題にしてよいのは、ジャンル・季節・買い物の習慣など**一般的な内容**だけ
- **作り話の体験談を書かない**（「昨日〇〇買った」「家族が〜」など）。観察・感想・問いかけにとどめる
- 楽天のイベント（お買い物マラソン、スーパーSALEなど）の**日付や還元率は書かない**（間違えやすいため）。「そろそろ」くらいの書き方にする
- NGワード・誇張のルールは、アフィリエイト投稿と同じく適用する
- 500文字以内。目安は30〜150文字の短文

## 書き方のコツ
- 返信したくなる終わり方（質問、共感を誘う一言）にする
- ハッシュタグは基本なし。付けても1個まで
